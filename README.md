# LeetCode Solutions

Welcome to my personal repository of LeetCode solutions. This repository serves as a log of my problem-solving journey and contains optimized solutions to various LeetCode problems across different topics and difficulties.

## 🚀 How It Works

This repository is organized to make it easy to find and understand the solution for any problem:

- **Categorization**: Problems are grouped into batches by their problem number (e.g., `0000-0099`, `0100-0199`) inside the `solution/` directory.
- **Problem Folders**: Inside each batch, every problem has its own dedicated folder named after the problem number and title (e.g., `0001.Two Sum`).
- **Detailed Explanations**: Inside each problem's folder, you will find a `README.md` containing:
  - The full problem description.
  - The algorithmic approach and logic used to solve it.
  - Time and space complexity analysis.
- **Multiple Languages**: The solutions are implemented in various programming languages including Python, Java, C++, JavaScript, Go, and more. You can open the respective solution file (e.g., `Solution.py`, `Solution.cpp`) to see the code.
